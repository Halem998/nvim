## Key Decisions Made

- The "possibly-comma-joined" heuristic (shared identically between the Phase 1 validate check
  and the Phase 2 script) flags a string only when it contains 2+ `, ` occurrences, or exactly
  one `, ` followed by 2+ non-initial capitalized name-like tokens in the remainder. This was
  chosen after testing a simpler heuristic against the live corpus and finding false positives on
  legitimate `"Last, First M."` entries (`"Gabbay, Dov M."`, `"Reynolds, Mark A."`).
- Both tools read/tested against the live `~/Projects/Literature/index.json` and a scratch copy
  of it, but never wrote to the live file — confirmed via `md5sum` and `git -C ~/Projects/Literature status` before/after.
