## Key Decisions Made

- The `VAR=$(cmd) || status=$?` guard is the sanctioned pattern for preserving a documented
  exit-code contract when migrating a `VAR=$(cmd); status=$?` pair to `set -e` — it is
  `-e`-exempt because the assignment is not the last command in the `||` list, and it preserves
  the real captured exit status (unlike a bare `VAR=$(cmd) || true`, which would discard it).
- `shell-strict-mode.md` (Phase 5) classifies the full `set -uo pipefail` and no-`set`-line
  populations across the whole `agent-system/extensions/**` tree, not just core. Only core files
  are in scope for Phases 6-8's actual migration; non-core files are classified but left as a
  residual for a future task.
