### Research Integration

The research report corrects the task description on two load-bearing points, and this plan is
built against the corrected picture, not the original framing:

1. **`mcp-server-ownership.md` contains no false premise sentence to delete.** Grep-confirmed
   zero occurrences of `.mcp.json`, "project-scoped", or "subagent" in that file. Its defect is
   an OMISSION: line 23 asserts user-scope `~/.claude.json` is "the only mechanism that registers
   an MCP server", and the "Not registration" subsection rebuts only *settings files*, never
   engaging with project scope at all. The fix is to ADD the missing surface plus its governing
   rule, not to hunt for a sentence to remove.
2. **The actual claim lives in `core/scripts/setup-lean-mcp.sh` lines 5-7** (now in `file_scope`):
   "Project-scoped `.mcp.json` servers require an interactive approval prompt that a subagent
   cannot satisfy, so registering in user scope -- never gated by per-server approval -- is the
   reliable choice." That is the true locus and this task corrects it.

The report also establishes: the Known-gaps table error is a *transposition* (`sec-edgar` sits in
epidemiology's row and is simultaneously missing from founder's -- two errors, not one);
`epidemiology`, `filetypes`, and `founder` fragments each become `{}` after the purge because the
dead blocks are their entire content; `uvx mcp-nixos` exposes exactly two tools (`nix`,
