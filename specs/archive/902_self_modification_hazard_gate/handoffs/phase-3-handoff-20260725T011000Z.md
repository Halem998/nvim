**Deviations from Plan**: Two implementation bugs found and fixed during manual verification
(not scope deviations): (1) `orchestrate-batch-admit.sh`'s `self_mod_match` needed `first`, not
`first // empty`, because it is bound via `as $sm_hit |` outside an array comprehension. (2)
`orchestrate-dry-run-report.sh`'s degraded-detection needed `jq -c '.self_modifying'`, not
`jq -r '.self_modifying // "null"'`, because jq's `//` treats literal `false` as falsy. Both are
recorded in their respective phase's progress file and inline in the plan file.

**What NOT to Try**: Do not copy `scopes_overlap_first`'s `first // empty` tail pattern
uncritically into any new predicate — check whether the result is consumed inside an array
comprehension (where `empty` is safe, meaning "skip this iteration") or via a top-level `as $x |`
binding (where `empty` silently kills the whole downstream pipeline for that candidate).
