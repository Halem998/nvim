## What NOT to Try
1. Testing the scripts directly from `agent-system/extensions/core/scripts/`: their
   `SCRIPT_DIR/../..` PROJECT_ROOT resolution (the same convention `memory-harvest.sh` uses)
   only resolves to the real repo root at the eventual `.claude/scripts/` deployment depth, not
   at the three-deep source location. Use a temporary local harness at repo-root depth instead
   (see phase-5-progress.json deviation entry).
2. `--argjson detail "${var:-{}}"` as a bash default-value pattern: a literal `{}` inside a
   `${VAR:-DEFAULT}` expansion corrupts non-empty values by appending a stray `}`. Resolve the
   default in a separate variable assignment first.
3. `tr -dc ... | head -c N` for random-string generation under `set -o pipefail`: `head` closing
   the pipe early sends `tr` a SIGPIPE, and pipefail propagates that as a script-aborting error.
   Append `|| true` to the pipeline.
