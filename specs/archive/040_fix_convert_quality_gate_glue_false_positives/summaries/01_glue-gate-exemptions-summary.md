## Overview

`sentence_boundary_glue_count` in `agent-system/extensions/literature/scripts/literature-convert.sh`
was rejecting otherwise-clean conversions of logic/math papers because its `[a-z]\.[A-Z]` regex
matched two benign, corpus-endemic patterns: `Ph.D.` bibliography entries and single-letter-variable
quantifier/binder notation (`∀x.P`, `∃y.E`, `∃x.Q`). The function now strips both exemption spans
before counting, leaving the `>= 3` threshold and the other four gate checks untouched, and both
polarities are locked in with new hermetic regression fixtures wired as required, non-skipping
assertions in the test suite.

## What Changed

- `agent-system/extensions/literature/scripts/literature-convert.sh` — `sentence_boundary_glue_count`
  body replaced with a two-pass exemption strip (`re.sub(r"Ph\.D\.?", ...)` then
  `re.sub(r"[∀∃λ][a-z]\.[A-Z]", ...)`) followed by the original `re.findall` on the residue;
  docstring extended with the two exemptions, the two real-paper empirical cases, and the
  strip-vs-lookbehind rationale.
- `agent-system/extensions/literature/scripts/tests/generate-test-fixtures.py` — added
  `build_biblio_quantifier_pdf` (negative fixture: `Ph.D. thesis,` bibliography entries + binder
  notation via `fitz.TextWriter` + `fitz.Font("helv")`) and `build_fused_word_pdf` (positive
  fixture: genuine zero-space fused sentence boundaries, no `Ph.D`/binder characters), with two new
  `main()` dispatch branches and an updated module docstring `Usage:` block.
- `agent-system/extensions/literature/scripts/tests/test-literature-convert.sh` — added Test 3
  (negative, strict exit 0 + final `.md`) and Test 3b (positive, strict exit 3 + `.rejected` + no
  final `.md` + rejection-reason grep), placed after the Test 2/2b block and before the
  supplementary no-TOC heading section.

## Decisions

- Kept the exact strip-then-count regex bodies from the research report and plan verbatim, rather
  than a negative-lookbehind rewrite, since both exemption spans fully contain the raw match span
  they exempt.
- Kept `λ` in the binder character class alongside `∀`/`∃` (a judgment call flagged by the research
  report) since it is the same single-letter-variable binder shape and changes neither named
  paper's outcome nor the synthetic fusion case.
- During the Phase 1 spike, discovered that `page.insert_text()` silently truncates a line wider
  than the page's usable width instead of wrapping it — the positive (fused-word) fixture's lines
  were kept under ~70 characters each to avoid clipping the intended fusion boundary.
- For the Phase 5 Criterion 1 offline replay, joined the two named papers' on-disk `chunk_*.md`
  fragments with a blank-line separator rather than naive concatenation — naive concatenation glued
  each chunk's trailing text directly to the next chunk's per-chunk citation header line, producing
  7 spurious hits unrelated to the actual fix.
